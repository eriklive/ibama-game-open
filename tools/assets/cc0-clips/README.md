# Clipes avulsos (CC0)

Clipes da Universal Animation Library da Quaternius que **não estão nas versões Standard**
(grátis) usadas por `build-anims.mjs`, só nas pagas. A biblioteca inteira é **CC0** (domínio
público), e estes arquivos vêm da cópia por clipe que o Cinevva hospeda
(https://app.cinevva.com/tools/animations), no mesmo esqueleto de 65 ossos dos nossos personagens.

| Arquivo | Clipe original | Biblioteca | Vira no jogo |
| --- | --- | --- | --- |
| `melee-knee.glb` | `Melee_Knee` | UAL 2 | `kick` (arrombamento; a perna estica por cima, à mão) |
| `idle-look-around-loop.glb` | `Idle_LookAround_Loop` | UAL 1 | `look` (susto do arrombamento: olha de um lado para o outro) |

Para baixar de novo:

```bash
curl -O https://cdn.cinevva.com/rt/clips/1/melee-knee.glb
curl -O https://cdn.cinevva.com/rt/clips/1/idle-look-around-loop.glb
```
